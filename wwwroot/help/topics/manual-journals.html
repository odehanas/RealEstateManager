Manual journals cover what the automatic postings cannot: accruals, corrections, deposit refunds, bank charges, reclassifications, and opening entries that do not belong to a sub-ledger.

Creating a journal

  1. Select New Manual Journal.
  2. Enter the Entry Date — the accounting date, which is the date the reports will use.
  3. Enter a clear Description explaining why the entry exists.
  4. Enter the Document Number and Reference Number where relevant.
  5. For each line: choose the Account, enter either a Debit or a Credit (never both), and add a line Description. Choose a Unit on lines that relate to a building, so they appear against the right property in P&L by Property.
  6. Add lines until total debits equal total credits. The running totals are displayed as you type.
  7. Select Save as Draft.
  8. Post it from Operations ▸ Journal Inquiry. Until then it is not in any report — see Draft, Post & Reset to Draft.
The balance rule is absolute

The system will not save a journal whose debits do not equal its credits, and will not accept a journal with fewer than two lines. If you see "Journal entry is not balanced", check for a line with an amount in both columns, or a typing error in one figure.

When development projects exist, a Development Cost column appears. Choose the project and cost category on a line posted to the project's own account to capitalise it into that project; choosing one sets the account for you. A project can only be chosen on its own account.

Write the narration for someone else

Six months from now, an auditor will read the description without any of today's context. Write it so that it explains itself: "Refund of security deposit, lease LSE-0042, tenant Al Noor Trading, cheque 100233", not "deposit refund".
