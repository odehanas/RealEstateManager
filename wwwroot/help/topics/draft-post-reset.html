Every accounting transaction in RealEstateManager goes through three states, the same way Odoo works. Understanding this one idea explains why a transaction you have just saved may not yet appear in the Trial Balance.

StateWhat it means
DraftThe journal exists and can be reviewed, but it has no effect on any report. The Trial Balance, Balance Sheet, Profit & Loss, ledgers and statements all ignore drafts.
PostedThe journal is in the accounts. Every report includes it.
Reset to DraftA posted journal pulled back out of the accounts so it can be corrected, then posted again.

Which screens post straight away, and which leave a draft

ScreenWhat Save / Post does
Customer Invoices, Vendor BillsThe Post button builds the journal and posts it in one click.
Customer Receipts, PDC Receipts, Security Deposits, Vendor Payments, Petty Cash, Manual Journals, Revenue Recognition, Recurring PrepaymentsSaving creates a draft journal. You then post it from Operations ▸ Journal Inquiry.
Fixed Assets (acquisition, capitalisation, depreciation)Posted immediately.
"I saved it but it is not in the Trial Balance"

That is almost always a draft waiting to be posted. Open Operations ▸ Journal Inquiry, set Posted Only to No, find the entry and press Post.

Posting drafts

  1. Open Operations ▸ Journal Inquiry.
  2. Set Posted Only to No so drafts are listed. Narrow it by date or source type if you like — for example only CustomerReceipt — and select Go.
  3. Review each draft. Press Post on one entry, or Post All Drafts to post every draft that matches the current filter.

Post All Drafts posts each entry separately. If one cannot be posted — for example because its date falls in a closed period — the others still go through, and the message lists the ones that failed and why.

When Post is refused

SituationWhat to do
The entry's date is in a closed periodNothing can be posted into a closed period. Re-date the document into an open one, or post a journal there.
A receipt or cheque clearance whose invoice is still a draftPost the invoice first, then the receipt or clearance.
A vendor payment whose bill is still a draftPost the bill first, then the payment.

A settlement must never reach the accounts before the invoice or bill it settles, or Accounts Receivable or Accounts Payable would be reduced by an amount that was never added. In Post All Drafts the invoice or bill is normally dated earlier and so is posted first, and its settlement follows in the same run.

Correcting a posted transaction

  1. Find the journal in Journal Inquiry and press Reset to Draft. It leaves the accounts immediately.
  2. Correct the source document. A vendor bill, for instance, becomes editable again once its journal is a draft.
  3. Post it again.

Resetting also undoes what posting did to the document. Resetting a receipt takes its amount back off the invoice it paid; resetting a cleared PDC puts the cheque back to Received.

When Reset to Draft is refused

SituationWhy, and what to do instead
The entry is in a closed periodThose figures have already been reported. Post a correcting journal in an open period.
An invoice has posted receipts or cleared cheques against itThe later transaction depends on it. Reset the receipts first, then the invoice.
A vendor bill has posted payments against itReset the payments first.
A PDC whose clearance has been postedReset the clearance entry first.
Year closing, prepayment set-up or amortisation, fixed asset postingsThese create schedules or close a year, so unwinding them is not a simple reset. Post a reversing journal.
Closed periods are locked in both directions

Nothing can be posted into a closed period and nothing can be reset out of one. The list screens show a Period locked badge instead of the buttons when this applies.
