Workflow step 2. A unit is an individually rentable space inside a property: an apartment, an office, a shop, a warehouse bay. Leases are signed against units, not against properties.

Creating a unit

  1. Select Add Unit.
  2. Choose the Property. The unit receives the next code under it, such as OWN-R-0001-U01.
  3. Enter the Floor and the Usage Type.
  4. Enter the Area (sq ft) and the Standard Annual Rent.
  5. Leave VAT Category blank to inherit the property's, or set it for a unit that is treated differently — a shop on the ground floor of a residential tower, for example.
  6. Leave Status as Vacant; the system changes it automatically. Save.
FieldMeaning
Unit codeIssued by the system, unique within its property.
Area (sq ft)Used for rent-per-square-foot and area utilization.
Standard Annual RentThe asking rent. Offered as the default when a lease is created, and editable there.
VAT CategoryBlank means inherit the property's. Set it only to override.
StatusVacant · Occupied · Under Maintenance · Reserved.
Status is maintained for you

An active lease sets the unit to Occupied automatically. Set the status yourself only for Under Maintenance or Reserved, which keep the unit out of the leasing flow.

The list is grouped by property so you can see each building's units and their occupancy together. Occupancy figures on the dashboard and in Property Utilization come from unit status, so keeping it accurate keeps the reporting accurate.
