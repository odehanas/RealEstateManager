Reporting ▸ Build Your Own Report

When none of the ready-made reports answers your question, build one: choose what to report on, the columns, the filters and the totals, and show the result as a table or a chart. Save it to run again, or share it with the company. Needs View Reports.

Building a report, step by step

  1. What do you want to report on? Choose one kind of record: properties, units, tenants, vendors, contracts, customer invoices, receipts, credit notes, post-dated cheques, security deposits, vendor bills and payments, journal entries and ledger lines, the chart of accounts, fixed assets, tenant service requests, owner settlements, unit sales, development projects, employees, leave, attendance, salary advances, payroll runs and payslips, contract approvals and payment approvals. You are offered only what your permissions let you see.
  2. Show either A list of records — tick the Columns you want; use the search box to find a field — or Totals by group: choose what to Group by (a date can be grouped by day, month, quarter or year) and what to Calculate: a count, or the total, average, lowest or highest of a number.
  3. Filters (optional): select + Add a filter for each condition, for example status is Posted, or invoice date within this year.
  4. Sort and size: the order, and the most rows to show.
  5. Show as a Table, Bar, Line or Pie chart. Charts use the groups and totals; for a list, the first text column and the first number column.
  6. Select Run report.

Using the result

  • Export to Excel (CSV) downloads the rows.
  • Print prints the table or chart.

Saving and sharing

  1. Under Save this report, give it a name, for example Rent by property this year.
  2. Tick Share with everyone in the company if colleagues should have it. Each person still sees only the data they are allowed to see.
  3. Select Save. After changing a saved report, Save updates it and Save as new keeps both.

Your own and shared reports are listed under Saved reports; select one to run it again with today's data.

For the accounts, use the financial reports

A built report lists and totals records as they are. Statements that must follow accounting rules — the Trial Balance, Profit & Loss, Balance Sheet and VAT Return — are under Financial Reports.
