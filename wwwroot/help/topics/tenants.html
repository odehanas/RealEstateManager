Workflow step 3. The tenant register is the receivables sub-ledger. Every tenant's balance rolls up into the 11200 Accounts Receivable control account.

Creating a tenant

  1. Select Add Tenant. The tenant code, such as TNT-00001, is issued when you save.
  2. Enter the Full Name exactly as it should appear on contracts, invoices and statements.
  3. Enter Email, Phone, Nationality and Address.
  4. Enter the identifiers you hold: Trade Licence Number for a company, Emirates ID / ID Number and Passport Number for an individual.
  5. Enter the TRN if the tenant is VAT registered.
  6. Enter the Opening Balance only when migrating from another system. Save.

Opening balances need a credit counterpart

Tenant opening balances add to the debit side of the opening trial balance. Check System Setup ▸ Opening Balances afterwards — see Opening Balances.

Giving the tenant portal access

The Portal button on a tenant's row issues them a login to the self-service portal, where they can see their account and send requests. See The Tenant Portal: Staff Guide.

The tenant's statement

Reporting ▸ Tenant Statement produces the tenant's running account: opening balance, every charge and payment in date order, and the closing balance. Use it for collection calls and for confirming a balance with the tenant.
