A transaction I saved is missing from a report

It is almost certainly still a draft. Manual journals, revenue recognition and prepayments save drafts. Receipts, PDCs, deposits, payments and petty cash post on save, but are kept as drafts if the posting was refused - a yellow message said why at the time.

  1. Open Operations ▸ Journal Inquiry.
  2. Set Posted Only to No, set the dates and select Go.
  3. Post the entry, or use Post All Drafts.

See Draft, Post & Reset to Draft.

"Reset to Draft" is greyed out or refused

Either the period is closed, or something depends on the entry — a receipt against the invoice, a payment against the bill, a posted PDC clearance. Reset the later transaction first, or post a correcting journal in an open period.

I cannot see the Add or Edit buttons on master data

Your account has View Master Data only. Ask the master data owner, or an administrator to change your permissions — see Master Data rules.

"…is already registered to…" when saving a tenant or vendor

The trade licence, ID, passport or TRN you entered belongs to an existing record, which the message names. Open that record instead of creating a duplicate. If it is genuinely a different party, check the number was typed correctly.

A vendor bill will not let me enter VAT

The supplier is not marked VAT registered, or has no TRN on file. Correct the vendor record if they are in fact registered — see Vendors. A bill already saved keeps the treatment it was saved with.

The Trial Balance does not balance

Because the system rejects any unbalanced journal, transactions cannot cause this. The cause is opening balances.

  1. Open System Setup ▸ Opening Balances.
  2. Read the Net Imbalance (Dr − Cr) card. It will equal the Trial Balance difference exactly.
  3. Identify the missing side. Debits exceeding credits means a credit-side opening balance is missing — almost always equity.
  4. Open System Setup ▸ Chart of Accounts, edit 31100 Share Capital or 32100 Retained Earnings – Prior Years, and enter the balancing figure.
  5. Return to Opening Balances and confirm the green Balanced badge, then re-run the Trial Balance.
Worked diagnosis

Trial Balance shows debits 375,000 and credits 175,000 — a difference of 200,000. The credit side contains only transaction balances, and Share Capital and Retained Earnings are both nil. The conclusion is that 200,000 of asset opening balances were entered with no matching equity opening balance. Entering 200,000 on 31100 or 32100 balances both the Trial Balance and the Balance Sheet.

The Balance Sheet does not balance

  • Check opening balances as in D.1 — the same difference appears in both reports.
  • Check that every prior fiscal year has been closed. Unclosed prior-year profit sits in revenue and expense accounts, which the Balance Sheet does not present.

Revenue is missing from the Profit & Loss

  • Run System Setup ▸ Revenue Recognition up to the report date. Invoicing alone does not create revenue.
  • Confirm the invoices themselves are Posted, not still in Draft.
  • For a managed property, remember only the commission is revenue — the rent belongs to the landlord.

A menu is not visible

  • Confirm the permission with your administrator (Companies, Users & Permissions).
  • Check that the company's subscription has not expired — expiry withdraws the processing menus.
  • Confirm you are in the right company using the company selector.

A tenant's balance looks wrong

  1. Run Reporting ▸ Tenant Statement for the tenant across the full period.
  2. Check for invoices still in Draft — they are not in the ledger.
  3. Check for PDCs still in Received status — the cash has not arrived yet.
  4. Check for a security deposit wrongly entered as a customer receipt.
  5. Confirm the tenant's opening balance was entered on the tenant record, not on the AR account.

A tenant cannot request maintenance

The tenant has an overdue invoice or a returned cheque not yet replaced, so maintenance requests are on hold. The portal tells them the amount. Once the money is received or the cheque replaced, the hold lifts by itself. See Tenant Requests.

New maintenance jobs are not assigned to anyone

No user has Carry Out Maintenance Jobs in this company. Give the maintenance engineer the Maintenance Engineer / Technician role — see Maintenance Jobs. A supervisor can assign waiting jobs from the job card.

A tenant is told "Invalid username or password"

Check the username and that portal access is active on the tenant's Portal Access page; reset the password there if needed. Tenants can sign in on the main Login page or the portal address.

A scanned invoice or ID could not be read

Reading uses the AI Assistant's OpenAI service. If it is not switched on, or the scan is unclear, enter the details by hand. A blurred photo, a password-protected PDF or a file over the size limit cannot be read.

After an update, a screen shows a database error

A message such as "Invalid column name" or "Invalid object name" right after a new version means a database change was not applied. Database changes now apply themselves when the site starts.

  1. The platform owner opens System Setup ▸ Database Updates.
  2. If the last start shows Stopped on an error, send that page to your developer. Do not run the script by hand in the hosting console: the application would not know, and would try it again.
  3. If it shows Up to date, the problem is elsewhere - report it through System Setup ▸ Send Feedback.
