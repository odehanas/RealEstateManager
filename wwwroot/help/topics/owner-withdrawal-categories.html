Categories are the list used to tag what an owner's withdrawals were spent on — school fees, travel, household costs. They are an analysis dimension on the owner's equity account, not expense accounts, so company profit is never affected. See Owner Withdrawals Explained for the reasoning.

A starter set is created for every company and can be renamed, reordered, deactivated or replaced entirely:

  1. Select New Category.
  2. Enter a unique Code and a Name.
  3. Add a Description so other users apply it consistently.
  4. Set the Sort Order to control where it appears in the selector and the report.
  5. Save.

The list screen shows, for each category, how many posted journal lines use it and the net amount posted against it — so you can see at a glance which categories are actually being used.

Deactivate rather than delete

A category already used by a posted journal cannot be removed, because those journals reference it. Untick Active instead: it disappears from the General Journal selector while every journal already posted against it, and every historical report, stays exactly as it was.
