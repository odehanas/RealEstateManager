Properties, units, tenants, vendors and contracts are master data: the records everything else refers to. Three rules keep them clean.

1. The system issues the codes

You never type a code. It is generated when the record is saved, and it never changes afterwards because it is already printed on contracts, invoices and statements.

RecordExampleHow it is built
PropertyOWN-R-0001OWN (owned) or MNG (managed), then the type — R residential, C commercial, W warehouse, M mixed use — then a running number.
UnitOWN-R-0001-U01The property code plus a unit number within that property.
ContractOWN-R-0001-U01-C001-2026The unit code, a tenancy number and the contract year. A renewal by the same tenant keeps the C number with the new year; a new tenant on the unit gets the next C number.
TenantTNT-00001A running number for the company.
VendorVEN-0001A running number for the company.
Vendor billBILL-2026-0001Year and running number. The supplier's own number is stored separately.
Tenant requestREQ-2026-0001Year and running number.

The property create screen previews the code it will issue as you choose the ownership and type.

2. The same party cannot be entered twice

A tenant or supplier set up twice under two codes splits their balance in two, so statements are wrong and the same debt gets chased twice. The system refuses a duplicate of any of these, within a company:

  • Tenants — trade licence number, Emirates ID / ID number, passport number, TRN.
  • Vendors — trade licence number, TRN.
  • Properties — the property name.

The message names the record that already holds the value, for example Trade licence number "1234" is already registered to TNT-00007 – Al Noor Trading. Open that record instead of creating a second one.

Blank values are never treated as duplicates. Any number of records may have no passport number on file.

3. Only the master data owners can create or change records

PermissionWhat the user can do
View Master DataOpen the lists and look records up. The Add and Edit buttons are not shown, and a note explains why.
Create & Edit Master DataAdd and amend properties, units, tenants and vendors, and issue tenant portal logins.

Accounting users can always look vendors up, because they need to find the supplier to enter a bill, but they cannot create one. Grant Create & Edit only to the small group responsible for master data — see Companies, Users & Permissions.
