Journal Inquiry is the audit trail and the place where drafts become postings. Every journal in the company — automatic or manual, draft or posted — is listed here with its entry number, date, description, source and value.

Finding journals

  1. Set the From and To dates.
  2. Optionally choose a Source Type to see only one kind of transaction.
  3. Set Posted Only to No to include drafts, or Yes to see only what is in the accounts.
  4. Select Go.

Every journal line carries the property, unit, tenant, lease, vendor and source document it came from, so any figure in a report can be traced back to the transaction that caused it.

Posting and resetting

ButtonWhat it does
PostPuts one draft into the accounts.
Post All Drafts (n)Posts every draft matching the current filter. Each is posted separately; any that cannot be posted are listed with the reason, and the rest still go through.
Reset to DraftTakes one posted entry back out of the accounts so its document can be corrected.
Period locked badgeShown instead of the buttons when the entry's period is closed.

Read Draft, Post & Reset to Draft for which screens leave drafts and when a reset is refused.

A good end-of-day habit

Filter today's date with Posted Only = No and post what is waiting. Drafts left behind are the commonest reason a report looks short.
